All data are generated by the code in the project repository from problem names and seeds; raw outputs, aggregation scripts (which write every number in this paper) and figure scripts are part of the code, and \texttt{code/run\_all.py} reruns everything. The tool is the \texttt{surroselect} package (MIT licence; copyright holder P N Bhargav Teja). The code, the raw outputs and the scripts will be made available on request from the corresponding author; no public repository or archive DOI has been created.
