# Protocol addendum v2.2 (pre-registered BEFORE Exp A2, E, A3, G, F were run; written AFTER seeing Exp A and Exp D, and after two independent AI audits)

**Triggers.** Two fresh-context AI audit agents (implementation; design & statistics — AI agents, not human reviewers) reported issues that I verified myself against the code and data before acting: (i) Exp A is carried by one family (nlheat supplies 88.3 % of P2's gain; without nlheat the N=1024 Spearman is +0.486); (ii) the A2 baseline rate p0 in addendum v2.1 was miscounted (2/20 stated; burgers_L1, f1 = −1.9972, ȳ = 2.25 makes it **3/20**); (iii) f1 is correlated with parameter dimension p (Spearman 0.708 across 24 instances; every instance with f1 < −2 has p = 3); (iv) the direct MLP beats the POD+MLP by > 0.1 decade in 17 of 24 instances at N=1024 (POD+MLP better in 1), so the "linear-subspace vs nonlinear-output" contrast is really *GP-ARD regression vs neural regression*; (v) the best neural error never falls below ≈ 6.6e-4 and neural batch size switches from N (N ≤ 512, 1500 steps) to 512 (N = 1024, 3000 steps), a float32/optimiser/step-count confound; (vi) the sampled search configs are shared across instances and N within a (method, seed).
**Nothing below changes the verdicts of H1a, H1b, H2, H4a, P1, P2, S1, D1 as pre-registered.** Wording change: the diagnostic result is reported as *criteria not met; inconclusive; carried by one family; confounded with p*, not as a disconfirmation.

## 1. Amendment to Exp A2 (made before A2 ran; A2 has no results)
* **p0 corrected** from 0.10 (2/20, miscounted) to **0.15 (3/20)**. **Q1 success:** exact one-sided binomial p < 0.05 at p0 = 0.15, i.e. **k ≥ 4 of 7** qualifying instances with ȳ(N=1024) ≥ 1.0 decade. (At p0 = 0.15, k = 3 gives p = 0.074.)
* **Family-level report (descriptive, not a test):** the 7 qualifiers come from 4 families (reacdiff, helm, heatp, diff1d); report the number of families in which all qualifying instances are decisive.
* **Q2 unchanged.** **Caveat fixed in advance:** 6 of the 7 qualifiers have p = 3 and the only non-qualifier (control) has p = 8, so A2 cannot separate f1 from p.

## 2. Exp A3 — probing the f1–p confound (descriptive, n = 4; no confirmatory power)
Instances (unit-tested): **darcylin_L1/L2** (p = 16, 32; nearly linear log-coefficient, σ = 0.2), **heatmv3_L1** (p = 3; moving narrow source), **incl3_L1** (p = 3; moving inclusion, fixed contrast). Pilot features were computed before any surrogate ran (`expA3_pilot_features.json`): f1 = −1.57, −1.60 (darcylin), −0.23 (heatmv3), −1.29 (incl3). **Observation:** nearly-linear high-p maps do *not* reach f1 < −2 (a linear map in p dimensions needs ≈ p modes, so a 4-mode statistic is mechanically bounded) — this is itself evidence that f1 partly proxies dimension.
**Predictions (decisive := ȳ(N=1024) ≥ 1.0):** under "f1 matters beyond p": heatmv3_L1 (f1 = −0.23) and incl3_L1 (f1 = −1.29) are **not** decisive (while all four p = 3 instances with f1 < −2 were, ȳ ≥ 2.58); darcylin instances (f1 ≥ −2) are not predicted decisive. Under "p = 3 is what matters" heatmv3_L1 would be decisive. Outcomes are reported per instance; a darcylin outcome ≥ 1.0 would show that f1 < −2 is not necessary for decisive LS wins.
Protocol: N ∈ {64, 256, 1024}, seeds 0–2, same 5 methods and settings as Exp A.

## 3. Exp G — is POD the driver? GP on the full field (no POD)
`gp_full`: one shared ARD kernel (Matérn-5/2 or RBF, trial 0/1 only, **B = 2**, documented) fitted by marginal likelihood on ≤ 300 points, all outputs jointly, no POD. 24 instances (v1 + Exp A), N ∈ {64, 256, 1024}, seeds 0–2. Compared with POD+GP on identical subsets in cells where POD+GP clearly beats the best NL (oracle) comparator (ȳ_gp > 0.10).
**G1 (POD truncation is not the driver):** median err_full/err_POD+GP ≤ 3 and ≥ 75 % of such cells ≤ 3. Otherwise G2 (POD basis matters beyond the regressor). Quartiles reported.

## 4. Exp F — is the neural error floor an optimiser / precision / step-count artefact?
10 instances: the 7 **decisive** (ȳ(1024) ≥ 1.0 in v1/Exp A: bratu_L1, bratu_L2, burgers_L1, nlheat_L1, nlheat_L2, darcy_L1, heat2d_L1) + 3 neural-clear (transport_L2, fisher_L2, heat2d_L2). For each stored best configuration of POD+MLP, MLP and Bottleneck at N ∈ {256, 1024}, seeds 0–2: **f64_adam** = float64, full-batch Adam, 6000 steps, cosine; **f64_lbfgs** = f64_adam followed by ≤ 400 L-BFGS iterations (strong-Wolfe, float64, full batch). Outcome: oracle-best NL error over {stored, f64_adam, f64_lbfgs} vs best LS (stored POD+GP/POD+Poly and best POD+MLP variant).
**Verdict rule (at N=1024, the 7 decisive instances):** *ARTEFACT* if ≥ 4 of 7 have ȳ_F < 1.0 (advantage falls below one decade) ; *ROBUST* if ≥ 5 of 7 keep ȳ_F ≥ 1.0; otherwise *PARTIAL*. Also reported: median improvement of the NL error floor (decades) and the smallest NL error reached.

## 5. Analysis-only commitments (no new runs)
(a) config-draw sensitivity: recompute ȳ from disjoint halves of the stored non-default trials; (b) tie-band sensitivity (0.05, 0.10, 0.15, 0.30) and seed sign-consistency reported next to every headline; (c) family-level / instance-level inference replaces cell-level wherever possible, cell-level tests flagged; (d) the Exp A bootstrap p-values recomputed with 10⁶ draws; (e) the 3-vs-2 member asymmetry and POD+MLP-vs-direct-MLP contrast reported; (f) the NN step-count change at N = 1024 quantified; (g) Exp B shift sign convention fixed (shift_toward_NL = y1500 − y6000; B2: median < 0.5) — a bug found by the audit before B was analysed.

## 6. Order and rules
Running/queued: B (running), A2, E → then A3, G, F. No change to methods, criteria or instances after the first result of each; failed configs = ∞; outputs preserved; deviations logged. All stage-3/4 experiments are post hoc in *motivation* and pre-registered in *prediction*.
