# Agent 5 - independent implementation audit

Scope: `Reinforced_Research_Project/code/src/surrogate_bench/*.py`, `code/experiments/*.py`, `code/configs/*.json`, `code/tests/*`, the three protocol documents, and `manuscript/static_v3.md` sections 3-4. No file other than this report was created in the repository. No experiment was started. Checks ran with 1 thread (scratch scripts live in the session scratchpad). All line numbers refer to the working tree as read today.

Bottom line: I found no FATAL or CRITICAL defect. In particular I found no train/validation/test leakage. Selection is by validation error only. POD, scalers and output standardisation are fitted inside `fit()` on the training rows. Pilot features use only `perm[:32]` of the training pool. The statistical routines are correct. I did find one latent sign-convention bug in the pre-specified Exp B criterion, several protocol-versus-text mismatches, and design asymmetries in the "matched" tuning that the code makes concrete and measurable. Most of these were already conceded in the register as RR-02 or as deviation D5.

## 2. Verified as correct

(a) Leakage and separation
- `run_method` (`hpo.py:12-25`): `iv`/`it` are a permutation of the N training rows. Trials fit on `X[it]`, validation uses `X[iv]`. `best = min(trials, key=val)`. The test and ext arrays are only used for logging and for the refit's scores. Refit uses `X` (all N) only.
- `POD` (`methods.py:27-32`): mean and SVD from the `Y` passed to `fit()`. In `PodPoly` the `StandardScaler` is fit on training features. `PodMLP` scale `s` uses the training singular value. `MLPDirect`/`Bottleneck` use the training mean/std. No object persists across fits (new class instance per call).
- `_x()` is a fixed affine map, not data-fitted.
- Pilot features: `experiment.py:27-28` feeds `d["u_train"][perm[:n0]]` with `perm = default_rng(1000+seed).permutation(POOL)`. `idx = perm[:N]`, so pilot rows are a subset of the training rows for every N >= 32 (A2: N>=64). `pilot_features` (`diagnostics.py`) uses only `Y`; the LOO loop removes the row under test before computing the mean and SVD.
- Train/test/ext parameter draws come from 3 distinct sha256-seeded streams (`data.py:11-24`). `draw_params` is deterministic and bit-identical to the cached `mu_*` for all 32 instances.
- Frozen rules (`freeze_rule.py`) read only `results/raw` (v1). `ridge_fit` inside `lofo_residuals` standardises on the training fold only, so fold standardisation does not leak.

(b) Matched tuning in code
- All 7 methods (5 + `pod_krr` + `pod_gp_iso`) go through the same `run_method`: B trials, trial 0 = `sample_config(..., trial=0)` independent of the RNG (no draws consumed at trial 0), same val split for every method at a given (seed, N), the same `rel_l2` metric, the same refit. Failed configs score `inf` (`hpo.py:20-21`). Across the three raw sets I scanned (v1, Exp A, Exp D) there were 0 non-finite trials of 20,736.

(c) Outcome definitions
- `family_y` (`analysis.py:28-38`) matches protocol §5 and manuscript §3: LS*/NL* = argmin `val_best` within the family, y = log10(err_NL*/err_LS*), seed-mean by `cell_table`. The tie band, the clear-LS/clear-NL classes (`analysis_v2.py:42`) and the "26%" gloss (10^0.1=1.259) are consistent. `h4` conditions (SYM b=8/8, ASYM LS b=1 NL b=8) match protocol §7.

(d) Statistics
- Holm (`stats.py:7-12`): equals an independent reference implementation on 200 random p-vectors. Hand-calculation test passes.
- Exact McNemar and sign tests: both are exact binomials on discordant pairs. `mcnemar_exact_greater(8,2)` equals 0.0546875.
- `perm_spearman_neg` (`analysis_v2.py:12-22`): exact enumeration for n<=9, one-sided rho<=obs, with the identity included. For n=6 random data it agrees with brute-force `scipy.spearmanr` enumeration (0.17778 vs 0.17778). For n=8, `p_min = 1/40320` is tested.
- LOFO ridge: holds out whole families (both levels), standardises inside the fold, leaves the intercept unpenalised, and uses the saved (mu, sd, beta, ym) consistently in `_pred`.
- Cluster bootstrap: resamples whole groups with replacement. Under a family-structured null feature (the repo's own generator, 8 clusters, 300 replications, n_boot=400) the false-positive rate at alpha=.05 was 0.03 and at .10 was 0.043. It is not anti-conservative in that setting.
- Wilcoxon, sign and binomial wrappers pass through scipy with the right alternatives. H1a is one-sided "greater" on y>0 (LS better); H1b counts rho<0.

(e) Randomness
- Current `hpo.py` uses `zlib.crc32`; no `hash()` anywhere in `src/` or `experiments/` (grep). The regression test spawns 3 subprocesses with different `PYTHONHASHSEED` values.
- `torch.manual_seed` is called before init and again inside `_train`, with a seeded `torch.Generator` for batch order. The test asserts that two fits with the same seed agree to 1e-9. `np.random.default_rng` is used throughout; bootstrap seeds are fixed. `Pool.map` preserves order in `build_dataset`; `imap_unordered` in `run` only affects log order, not the data.

(f) Solvers
- Darcy assembly is symmetric (harmonic face means, edge-padded boundary values), and the sub-sampling [1::2,1::2] gives 16x16=256 outputs. Upwind advdiff uses the right operator for b>0, with the outflow Dirichlet layer. Transport and wave CFL <= 0.5. Wave start-up step and step count land exactly at T. Burgers IFRK4 stage formulas are the standard ones. KdV integrating factor sign is correct (u_t = -u_xxx -> exp(i k^3 t)) and the soliton test passes. Fisher Strang splitting with a Neumann CN system has the right end-point stencil (1+lambda), and the front speed test passes. Bratu Newton converges from u=0 to the minimal branch. Reaction-diffusion and Helmholtz manufactured-solution tests pass.
- The 4096 x p draws were solved within parameter ranges that remain positive and well-posed under affine extrapolation (c, x1, w, a2, delta, D, r, sigma, beta, R, kappa, alpha all stay >=0).
- Extra checks run by me: mesh/time-step convergence for heat2d_L2, bratu_L2 at mu=1.25, darcy_L2 (n=31 vs 127: 3e-3), burgers_L2, fisher_L2 (extreme ext), wave_L2, transport_L2; all within a few percent or better, with advdiff_L2 as the exception (F12). `nlheat` ext solutions have min(1+beta u^2)=0.37>0. Fisher ext fronts essentially never reach the right boundary (<=1.6% at x=1 above 0.05).

(g) Manuscript sections 3-4 vs code
- Matching: 80/20 split with validation-based selection and refit on all N; B=8 with trial 0 default; Adam, cosine, 1500 epochs, float32; POD+GP (ML-II on <=300 points, 4 leading modes, remaining modes reuse kernel 4); Poly (degree<=6, <=5,000 features); bottleneck k in {2,4,8,16}; KRR and GP-iso as described; N levels (6, or 3 for A2/E); seeds 0-2; pilot n0=32 with f1 = log10 of mean LOO r=4 relative error and f2 = log-slope over 10 modes; 4096/1000/500 pools; 16+8+8=32 instances; seed-specific permutations with nested subsets; Holm over {H1a,H1b,H2,H4a} and {P1,P2}.
